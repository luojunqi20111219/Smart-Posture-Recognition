# NodeSync 姿态识别

一款基于 Android CameraX + ML Kit 的实时人体姿态识别应用，支持扩胸运动和高抬腿动作检测。

## ✨ 功能特性

- 📷 **实时姿态检测** - 使用设备摄像头实时识别 33 个人体关键点
- 🔄 **前后摄像头切换** - 支持前置/后置摄像头自由切换
- 🔊 **语音播报反馈** - TTS 语音实时指导动作是否标准
- 📊 **双模式检测**
  - **扩胸运动模式** - 检测手臂抬升角度和肘部弯曲程度
  - **高抬腿模式** - 检测大腿抬升角度和膝盖弯曲状态
- 🎨 **可视化骨骼线** - 实时绘制人体骨骼连接线
- 🎯 **智能动作评估** - 基于角度计算判断动作标准程度

## 🎯 使用说明

1. **打开应用** - 授予相机权限
2. **选择模式** - 当前支持扩胸运动和高抬腿
3. **对准摄像头** - 确保全身在画面内
4. **跟随语音指导** - 根据提示调整动作
5. **查看反馈** - 屏幕显示实时角度数据

### 扩胸运动标准
- 双臂抬升到水平位置（约 90°）
- 手肘弯曲约 90-120°
- 避免"投降"姿势（小臂端平）

### 高抬腿标准
- 一腿站直支撑（角度 < 30°）
- 另一腿抬起（大腿 45-130°）
- 抬起腿膝盖弯曲（70-170°）
